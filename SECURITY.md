# Security policy

## Supported versions

Security fixes are provided for the latest released Chrome Web Store version
and the current default branch.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for this repository. Include the
affected version, impact, reproduction steps and a proposed mitigation when
available.

Do not publish credentials, cookies, private video URLs or exploit details in a
public issue. If private vulnerability reporting is unavailable, open a public
issue containing no sensitive details and ask the maintainer for a private
contact channel.

The project aims to acknowledge reports within seven days. Actual response
times depend on maintainer availability.

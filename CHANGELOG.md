# Changelog

This project follows semantic versioning for public releases.

## Unreleased

### Added

- CC-CEDICT-backed word definitions and dictionary-aware longest segmentation.
- Manifest V3 dictionary service worker.
- ESLint, Prettier, JavaScript type checking and enforced coverage.
- Chromium extension end-to-end testing and dependency update automation.
- Open-source licensing, security, contribution and architecture documentation.

### Changed

- The large dictionary no longer loads into every Bilibili content script.
- Settings and definition-card UI use a restrained production visual style.

### Removed

- The `Replay last 3 seconds` definition-card action.

## 0.1.0

- Initial local-first Bilibili learning-caption MVP.
